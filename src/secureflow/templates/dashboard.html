AI 연결

내 PC에 로그인된 Codex·Claude Code 또는 Ollama

선택 기능

secureflow setup --ollama로 경량 모델 2종을 설치합니다. 앙상블은 두 모델을 순차 실행하며 한 모델 실패 시 나머지 결과를 보존합니다.

Codex는 터미널에서 codex login, Claude Code는 claude auth login으로 먼저 로그인하세요. 구독 한도와 모델 접근 권한이 적용됩니다. 소스 발췌가 해당 제공자로 전송되며 이 앱은 로그인 토큰을 수집하지 않습니다. Ollama는 외부 전송 없이 PC에서 추론합니다.

AI는 어디에 쓰이나요?

선택한 모델이 코드 맥락과 분석 자료를 검토해 추가 가설 및 수정 방향을 제안합니다.

기본 진단과 별도로 실행되므로 AI 응답이 늦어도 빠른 리포트를 확인할 수 있습니다.

AI를 끈 상태에서도 코드·동적 진단과 리포트 생성은 동작합니다.

새 진단 시작

심층 분석은 최대 3회 모델 호출로 더 오래 걸리고 구독 사용량을 더 사용합니다. 앙상블은 위 구독 연결과 별개로 로컬 Ollama를 사용합니다. AI가 없거나 실패하면 일반 진단으로 완료됩니다. 모든 AI 발견은 미검증 가설입니다.

기본 진단이 끝나면 빠른 리포트가 생성됩니다. AI 결과는 통합 리포트에 반영됩니다.
