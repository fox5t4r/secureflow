# 평가 설계

최종 표본은 OWASP 2025 10개 범주, 20개 메커니즘, 취약20/개선20 총40개 사례입니다.
manifest에는 경로·유형만 포함합니다. 검증기는 실제 HTTP 응답으로 판정하고 diagnostics.json 저장 후 별도 ground_truth.json을 읽어 평가합니다.

Bandit 1.9.4 기본 규칙으로 같은 40개 파일을 검사했습니다. 경고가 하나 이상인 파일을 baseline 양성으로 간주합니다. 원본 경고19개는 보존하고 사례 단위로 중복을 합칩니다.
검토 필요 경고를 취약점 양성으로 간주한 지표이므로 Bandit 자체의 일반적 FPR이 아닙니다.

동적 검증은 정적 경고 없는 사례도 검사하며 앱별 지식과 상태 관측을 추가로 사용합니다.
음성 사례에 비보안 MD5·고정 테이블명 SQL 보간 등 경고가 나기 쉬운 맥락을 의도적으로 포함했습니다.
따라서 정보량이 동일한 도구 순위 실험이나 실제 코드 분포의 무작위 표본이 아닙니다.

| 지표 | Bandit 후보 | 동적 검증 |
|---|---:|---:|
| TP | 10 | 20 |
| FP | 7 | 0 |
| TN | 13 | 20 |
| FN | 10 | 0 |
| FPR | 35% | 0% |
| Precision | 58.8% | 100% |
| Recall | 50% | 100% |

FPR=FP/(FP+TN), FDR=FP/(TP+FP), Precision=TP/(TP+FP), Recall=TP/(TP+FN).
개선폭=(기준선 FPR−검증 후 FPR)×100, 단위 %p.
HTTP115회, 미확인0, 감소35%p로 이 표본에서는 목표20%p를 충족합니다.
일반화된 정확도·통계적 유의성은 주장하지 않습니다. 보류 표본과 독립 수동 판정이 후속 과제입니다.

confirmed는 정상 대조군과 문제 동작 관측, not_reproduced는 주어진 입력에서 미재현,
inconclusive는 통신/대조군 실패입니다. 미재현은 안전 판정이 아닙니다.
미확인이 있으면 커버리지를 낮추고 목표 달성 판정을 막습니다. 보수적 지표도 함께 저장합니다.
AI 가설은 확정 수와 평가에 포함하지 않습니다.

Juice Shop에는 전체 정답표가 없으므로 FPR을 계산하지 않습니다.
여기서 얻은 35%p를 Juice Shop이나 AI 성능에 적용하면 안 됩니다.
오탐 감소는 정상/비정상 대조와 앱별 상태 검증에서 발생했습니다.

원본 측정은 실행별 .local/artifacts/<run-id>/results.json에서 확인합니다.
공개 저장소에는 개인 실행 아티팩트를 포함하지 않습니다.
