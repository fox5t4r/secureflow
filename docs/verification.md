# 검증 기록

## v0.2 변경

src layout와 설치 가능한 wheel, 작업 조정 분리, 인증/대상 웹 처리 분리,
자동 escape HTML 템플릿, 환경 독립 경로, 고정 버전 실습 설치, 선택적 CLI 구독 AI,
3단계 심층 분석, 공개 파일 allowlist 검사를 추가했습니다.

실제 로그인된 Codex CLI0.169.0과 gpt-6.1-terra(high)로 소스 검토→반론→통합을 수행했습니다.
세 단계가 완료되고 파일·행 인용이 검증된 미검증 가설을 생성했습니다.
Claude Code2.1.202는 설치·어댑터 테스트만 수행했으며 로그인되지 않아 실제 추론은 미검증입니다.

전체 테스트와 새 설치/브라우저 인수 결과는 로컬 .local 아래 보존합니다.
일반 GitHub clone에는 계정정보·원본 진단 리포트가 포함되지 않습니다.
같은 절차는 README와 scripts/verify_dashboard.py로 재실행할 수 있습니다.

고정 release 소스를 새로 내려받아 실제 대시보드에서 Codex 고급 모델의 심층 분석,
Semgrep·ZAP 비교, 계정 연결, 빠른/통합 리포트 다운로드를 확인했습니다.
AI 실행 중 빠른 리포트가 준비됐고 세 단계가 모두 완료됐습니다.
새 release에서도 DAST6/7, Semgrep39후보, ZAP4경고유형이 관측됐습니다.
모바일 가로 넘침과 JavaScript 오류는 없었습니다.

wheel을 별도 빈 가상환경에 설치하여 실제40사례 워크플로우와 웹 템플릿·정적 파일·인증을 확인했습니다.
일반 검사만 실행, CLI 미설치, 연결 실패, 타임아웃, 응답 형식 오류, 사용량 제한,
앙상블 한 모델 실패/두 모델 실패, 대상 통신 실패를 회귀 테스트에 포함합니다.

실제 qwen2.5-coder:1.5b와 qwen2.5:0.5b 두 모델의 독립 검토가 완료됐습니다.
초기 보조 모델의 잘린 JSON은 실패로 처리하고 성공한 앞 모델 결과를 보존하는 것을 관측했습니다.
이후 출력 개수·길이·인용 선택지를 제한하여 두 모델 모두 완료되는 것을 확인했습니다.
실제 서버에서도 AI 미선택과 연결 불가 상황 각각 일반7개 검사·두 리포트가 완료됐습니다.
앙상블을 선택한 실제 브라우저 흐름에서도 관리자 로그인·계정 연결·7개 진단·Semgrep·ZAP·두 모델·두 보고서 다운로드가 완료됐습니다.
자동 테스트는 현재24개이며 wheel 설치 환경과 Docker에서도 실행합니다.

Ruff와 Prettier 형식 검사, 자체 코드 Bandit 검토도 수행했습니다.
남은 subprocess 경고는 명시적 인자 배열로 호출하는 도구 실행에 해당하며 shell=True를 사용하지 않습니다.
의도적으로 취약한 실습 구현은 별도 디렉터리에 두고 운영 코드 점검에서 구분합니다.
실습 검증용 MD5/SHA-1 비교에는 비보안 용도임을 코드에서 명시했습니다.

## 기존 실험

40개 자체 사례: OWASP2025 전체10범주, 20가지 메커니즘, 실제HTTP115회.
Bandit TP10/FP7/TN13/FN10 → 동적 검증 TP20/FP0/TN20/FN0.
FPR35%→0%, 감소35%p는 합성 표본 한정 결과입니다.

Semgrep39코드후보, ZAP4경고유형을 관측했습니다.
원본 개발 checkout은 release 태그와 같지 않으므로 새 고정 release 설치 결과와 구분해야 합니다.
